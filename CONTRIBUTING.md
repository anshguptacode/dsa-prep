# Contributing to DSA Repo

Thank you for considering contributing to this repository! Contributions can include:
- Improving existing solutions with clearer code or better performance
- Adding new problems and relevant C++ implementations
- Fixing bugs and refining comments or documentation
- Creating build scripts and helper tools
- Improving the repository structure and README

## How to contribute
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Make your changes with clear commit messages.
4. Submit a pull request with a concise description.

## Coding style
- Use modern C++ (C++11 or later).
- Prefer descriptive variable names.
- Add comments for non-trivial logic.
- Keep solutions self-contained in a single file.

## Build and test
- Use the provided `build_all.bat` to compile all solutions on Windows.
- Keep repository binaries excluded by `.gitignore`.
